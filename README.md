# 🚚 LogiTrack API
API REST para gestão de frotas e logística desenvolvida com **Java 17** e **Spring Boot 3**.

### 🛠️ Tecnologias
- Java 17 / Spring Boot 3
- Spring Data JPA
- PostgreSQL
- Docker

### 🚀 Status
Estruturando o domínio de veículos e controle de status.

## 🛠️ Como rodar o projeto localmente

1. Suba o banco de dados: `docker-compose up -d`
2. Execute a aplicação: `./mvnw spring-boot:run`
3. Acesse a API em: `http://localhost:8080/api/veiculos`
